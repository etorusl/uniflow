# Клиент UniFlow

Приложение для веба и Android на TypeScript, React Native, Expo и Expo Router. Реализованы учётная запись, профиль, предметы, преподаватели, расписание, личные задания и статистика. Следующие возможности отражены в [плане](../../docs/development-plan.md).

- `src/app` — маршруты и сборка экранов.
- `src/features` — функции продукта; каталоги появляются вместе с реализацией.
- `src/platform` — различия веба и Android: сессия, уведомления и файлы.
- `src/shared` — тема, оболочка и общие компоненты.

Команды запускаются из корня: `pnpm dev:web`, `pnpm dev:mobile`, `pnpm dev:android`, `pnpm build:web`. `dev:android` собирает и устанавливает development build, используя уже запущенный Metro на порту 8081; сначала запустите `pnpm dev`. `pnpm android:devices` показывает подключённые устройства, `pnpm android:connect` связывает локальные порты API и Metro с выбранным устройством через ADB. Адрес API задаётся публичной переменной `EXPO_PUBLIC_API_URL` в корневом `.env`. Генерируемые типы и HTTP-клиент импортируются из `@uniflow/api-client`; серверные модели Prisma сюда не попадают.

Нативные проекты генерируются из конфигурации Expo и config plugins. Их постоянные ручные изменения не используются, каталоги `android/` и `ios/` игнорируются Git. Собственная development build нужна для проверки нативных интеграций; веб не требует установленного Android SDK.

Полная инструкция — в [README](../../README.md). Офлайн-синхронизация отложена.
