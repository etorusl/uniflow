# Клиент UniFlow

Общее приложение для веба и iOS на TypeScript, React Native, Expo и Expo Router. Сейчас каталог содержит структуру исходников; исполняемое приложение создаётся на [этапе 1](../../docs/development-plan.md).

## Каталоги

- `src/app` — маршруты и сборка экранов. Предметная логика располагается в функциях, а не в файлах маршрутов.
- `src/features` — учётная запись, профиль, предметы, расписание, задания, группы, материалы, уведомления и статистика. Каталоги отдельных функций создаются вместе с реализацией.
- `src/platform` — адаптеры веба и iOS для сессий, уведомлений и файлов. При необходимости используются файлы `.web.ts` и `.native.ts`.
- `src/shared` — базовые компоненты, тема и общие клиентские утилиты.

Клиент использует `packages/api-client`, генерируемый из серверного OpenAPI. Модели Prisma и серверные инфраструктурные зависимости в приложение не импортируются. Данные сохраняются через сервер; офлайн-синхронизации в первой версии нет.

Веб-интерфейс адаптируется к телефону и компьютеру. iOS проверяется собственной development build уже при создании основы. Нативные проекты генерируются из конфигурации Expo и config plugins; постоянные ручные изменения в сгенерированных каталогах не используются.

Команды запуска и требования к версиям добавляются после создания и проверки исполняемого каркаса. Общие решения — в [README](../../README.md) и [архитектуре](../../docs/architecture.md).
