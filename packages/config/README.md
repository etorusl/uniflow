# Общая конфигурация инструментов

Workspace-пакет `@uniflow/config` экспортирует базовый TypeScript-конфиг и ESLint flat config. Корневые команды `pnpm lint`, `pnpm typecheck`, `pnpm format:check` проверяют соответствующие части workspace.

Клиент использует совместимый с Expo TypeScript-конфиг; сервер расширяет общий конфиг с NodeNext и метаданными декораторов NestJS. Генерируемые исходники и нативные каталоги Expo исключены из линтера. Настройки окружения и секреты сюда не входят.
