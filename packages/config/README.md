# Общая конфигурация инструментов

Будущий workspace-пакет для общих настроек TypeScript, ESLint и форматирования. Конфигурации добавляются на первом этапе вместе с реально запускаемыми проверками.

Клиент и сервер могут расширять общие настройки с учётом платформы. Пакет не содержит конфигурации окружения приложения и секретов.
