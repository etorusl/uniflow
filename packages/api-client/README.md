# API-клиент UniFlow

TypeScript-пакет `@uniflow/api-client` содержит HTTP-клиент на openapi-fetch и типы из серверного OpenAPI. Используется веб- и Android-приложением.

После изменения серверного контракта выполните из корня `pnpm build:server` и `pnpm api:generate`. Команда обновляет `apps/server/openapi.json` и `src/schema.d.ts`. Генерируемые файлы коммитятся вместе с кодом и не правятся вручную. `pnpm api:check` проверяет их актуальность без постоянного изменения файлов.

Пакет не содержит моделей Prisma, правил авторизации, серверной конфигурации или секретов. Наличие типов не заменяет проверку данных и прав на сервере.
