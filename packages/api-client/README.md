# API-клиент UniFlow

Будущий TypeScript-пакет с клиентом и транспортными типами, сгенерированными из OpenAPI серверного приложения. Используется веб- и Android-клиентом.

Источник контракта — серверная OpenAPI-схема. Генерируемые файлы не правятся вручную. Способ генерации, имя workspace-пакета и проверка актуальности добавляются при создании исполняемой основы.

Пакет не содержит моделей Prisma, правил авторизации, серверной конфигурации или секретов. Наличие типов не заменяет проверку данных и прав на сервере.
