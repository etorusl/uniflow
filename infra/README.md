# Инфраструктура UniFlow

- `compose/` — будущие Docker Compose-конфигурации локальных PostgreSQL, SeaweedFS с S3 API и Mailpit.
- `proxy/` — будущая конфигурация маршрутизации веба и API, а также HTTPS для соответствующего окружения.

Конфигурации пока не созданы. Запуск, порты, переменные окружения, тома и проверки готовности документируются на первом этапе после проверки сервисов. Пароли и ключи хранятся вне Git; `.env.example` содержит только безопасные примеры.

Локальные данные сервисов сохраняются в Docker volumes либо в игнорируемом каталоге `infra/data/`. Остановка окружения не должна удалять данные по умолчанию; команда сброса, если она добавлена, явно обозначается как удаляющая данные.

Конфигурация размещения на сервере и инструкция резервного копирования добавляются на этапе подготовки выпуска. Локальная конфигурация не считается готовой конфигурацией публичного размещения.
