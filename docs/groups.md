# Закрытые учебные группы

Раздел «Группы» открывает список групп пользователя, создание группы и вступление по коду или ссылке. Внутри группы есть задания, материалы, список участников и доступные по роли настройки. В карточке группы можно связать её с личным предметом. Связь видит только владелец этого предмета.

## Приглашения и роли

У действующей группы один владелец. При создании им становится автор группы. Владелец может передать владение действующему участнику, после чего сам становится модератором. Чтобы выйти, владелец сначала передаёт владение либо архивирует группу.

| Действие                                              | Участник | Модератор                            | Владелец                 |
| ----------------------------------------------------- | -------- | ------------------------------------ | ------------------------ |
| Состоять в группе, видеть задания и материалы         | Да       | Да                                   | Да                       |
| Публиковать задания и материалы                       | Да       | Да                                   | Да                       |
| Изменять свою публикацию                              | Да       | Да                                   | Да                       |
| Удалять чужую публикацию                              |          | Да                                   | Да                       |
| Создавать приглашения                                 |          | Да                                   | Да                       |
| Отзывать приглашения                                  |          | Свои                                 | Любые                    |
| Исключать участника                                   |          | Только участника без роли модератора | Участника или модератора |
| Назначать модераторов, снимать блокировку             |          |                                      | Да                       |
| Изменять или архивировать группу, передавать владение |          |                                      | Да                       |

Секрет приглашения содержит 20 символов и выдаётся только при создании. Его можно скопировать как код или отправить ссылку. Приглашение по умолчанию действует 168 часов и допускает 25 вступлений. Можно задать от 1 до 720 часов и от 1 до 250 вступлений. API хранит SHA-256 секрета и ограничивает число попыток по аккаунту. Повторное принятие действующим участником не расходует лимит. Ошибка одинакова для отозванного, истёкшего, исчерпанного приглашения или заблокированного пользователя.

Если гость открывает ссылку в вебе, после входа или регистрации приложение возвращает его к приглашению и ждёт подтверждения. Код работает и в Android. Для ссылок между устройствами нужен доступный этим устройствам HTTPS-адрес веба. Локальная веб-ссылка с `localhost` предназначена для окружения разработчика.

При исключении пользователь теряет доступ и не может вступить снова, пока владелец не снимет блокировку. Снятие блокировки оставляет пользователя вне группы до принятия действующего приглашения. Вышедший добровольно может вступить по действующему приглашению. Повторное вступление возвращает роль участника. Список группы содержит отображаемые имена и идентификаторы. Email не выдаётся.

## Задания и статистика

- **Индивидуальное выполнение** даёт каждому действующему участнику собственную отметку. Историю этой отметки видит сам участник. Ранее скрытая отметка того же пользователя восстанавливается после повторного вступления.
- **Общее выполнение** даёт группе одну отметку и общую историю. Завершать или возвращать в работу может автор, модератор или владелец при действующем членстве.
- Режим задаётся при создании. Состояние «вовремя» вычисляется по снимку дедлайна на момент завершения. Повтор запроса не создаёт дополнительное событие.
- Вступивший видит все опубликованные задания группы. Индивидуальные задания с прошедшим сроком попадают в личный список как просроченные, пока участник их не выполнит.
- Личная статистика включает личные и индивидуальные групповые задания действующих членств. Она полностью исключает общие задания. Прогресс внутри группы считает только общие задания этой группы.
- Добровольный выход и исключение прекращают доступ к содержимому группы, её истории и вложениям. Её задачи уходят из текущей личной статистики. При повторном вступлении личная статистика снова учитывает опубликованные задачи и собственные отметки.
- Удалённое задание скрывается из API и текущих расчётов. Архивация отключает доступ к группе и отзывом завершает действие её приглашений. Записи и отметки остаются в базе для внутренней истории. Пользовательского восстановления из архива пока нет.
- Авторство сохраняется после выхода автора. Владелец и модераторы могут удалить оставшуюся публикацию или закрыть общее задание. При повторном вступлении автор снова может редактировать свою публикацию.

## API и хранение

API под `/api/v1/groups` проверяет действующее членство для вложенных ресурсов. Маршрут `GET /api/v1/groups/tasks` возвращает видимые задания всех групп пользователя с пагинацией и фильтрами по группе, режиму и состоянию. `GET /api/v1/groups/{groupId}/statistics` считает общий прогресс одной группы. `GET /api/v1/statistics/me` считает личный прогресс.

Prisma хранит личные и групповые задания отдельно. `StudyGroup.ownerId` задаёт владельца. Роль владельца вычисляется при ответе, остальные роли хранятся в `GroupMember`. Миграция добавляет отложенный внешний ключ владельца на членство. Создание группы и членства, передача владения, смена роли, удаление и принятие приглашения выполняются транзакционно. Изменения, касающиеся одной группы, берут блокировку строки группы, чтобы проверка членства оставалась согласованной с записью.

Состояние общего задания хранится в `GroupTask`, индивидуальное состояние в `GroupTaskCompletion` с составным ключом задания и пользователя. События пишутся в `GroupTaskEvent`. Действия управления членством и архивом сохраняются в `GroupAuditEvent`. Удаление аккаунта в дальнейшем должно сначала передавать владение группой или обрабатывать её архив явно.
