# Проектирование UniFlow для Android

Самостоятельный комплект по существующему Android-приложению UniFlow. Содержит функциональное, интерфейсное и техническое проектирование. Рабочий код приложения не меняется.

## Материалы

- [Отчёт Word](deliverables/uniflow-android-design.docx).
- [Отчёт PDF](deliverables/uniflow-android-design.pdf).
- [Отдельный проект Figma](https://www.figma.com/design/G5td2BUaPyTcOFqbkGbQQR): дизайн-система Android и шесть мобильных экранов. Результаты проверки указаны в [figma.json](figma.json).
- [Полный справочник API HTML](api-reference.html) и [Markdown](07-api.md).

Для передачи вне репозитория приложите всю папку `android-design`. Каталог API содержит все 77 операций и 61 схему, показывая поля контракта, используемые Android-клиентом.

## Обновление

Из корня репозитория выполните генераторы на Python с Pillow и python-docx:

```sh
python3 docs/android-design/tools/build_design.py
python3 docs/android-design/tools/build_api.py
python3 docs/android-design/tools/build_diagrams.py
python3 docs/android-design/tools/build_report.py
python3 docs/android-design/tools/validate_docs.py
```

Генератор макетов создаёт предварительные изображения и код импорта. Проверенные PNG шести экранов, экспортированные из Figma, он сохраняет без перезаписи. Он не отправляет изменения в Figma автоматически. В исходном OpenAPI ничего не изменяется. PDF получают конвертацией Word через LibreOffice, после чего проверяют каждую страницу. `figma-plugin` содержит проверяемый код нативного импорта; повторный запуск сборки в уже заполненном файле останавливается во избежание дублей.

## Проверка результата

Проверены 36 сценариев, покрытие 77 API-операций и 61 схемы, все 26 моделей Prisma, локальные ссылки и отсутствие упоминаний других клиентских платформ. Все 41 страница Word/PDF просмотрены после конвертации. Шесть экранов шириной 390 dp экспортированы из Figma и проверены целиком; поля входа и профиля приведены к ширине карточек. Функциональный код приложения не менялся.
