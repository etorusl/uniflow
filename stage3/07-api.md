# API Android

## Контракт
[OpenAPI JSON](openapi.json) содержит полный контракт. [HTML-справочник](api-reference.html) содержит 77 операций, параметры, тела запросов и схемы ответов. Его можно открыть после скачивания.

Базовый адрес локального API имеет вид http://localhost:3000/api/v1. Адрес для Android зависит от подключения устройства к серверу.

## Форматы
Обычные тела передаются в application/json. Идентификаторы имеют формат UUID. Даты передаются как YYYY-MM-DD, локальное время как HH:mm, дедлайны как ISO 8601 с часовым смещением. PATCH принимает поля своего DTO. Неизвестные поля отклоняются.

## Доступ
Регистрация, вход, запрос восстановления, установка нового пароля и проверки доступности открыты без сессии. Остальные операции требуют Authorization со значением Bearer и токеном. При входе обязателен x-uniflow-client со значением native.

## Ошибки
400 означает некорректные данные, 401 отсутствие действующей сессии, 403 недостаток прав, 404 отсутствие или недоступность ресурса, 409 конфликт, 429 превышение числа попыток, 500 внутренний сбой. Код 503 у проверки готовности означает недоступность зависимостей.

В OpenAPI описаны общие ошибки по типам операций. Условия предметных ошибок зависят от данных. Контракт адаптирован для Android по сохранённым схемам и документации сервера. Новые запросы при редактуре не выполнялись.
