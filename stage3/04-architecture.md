# Архитектура и технологии

## Общая структура
Приложение Android обращается к REST API. Сервер проверяет данные и права и сохраняет записи в PostgreSQL. Содержимое файлов хранится в закрытом S3-совместимом хранилище. Отдельный фоновый процесс обрабатывает письма и напоминания.

## Технологии
| Часть | Выбор |
| --- | --- |
| Android | TypeScript, React Native, Expo, Expo Router |
| Сервер | TypeScript, NestJS |
| API | REST и OpenAPI |
| База | PostgreSQL и Prisma |
| Очередь | pg-boss |
| Файлы | S3, локально SeaweedFS |
| Почта | SMTP, локально Mailpit |
| Уведомления | FCM |
| Локальная инфраструктура | Docker Compose |

React Native и Expo обеспечивают экраны, навигацию и работу с Android. NestJS разделяет сервер по функциям. PostgreSQL поддерживает связи и транзакции. Prisma задаёт таблицы и миграции. pg-boss использует ту же базу для фоновых заданий.

## Модули
Аккаунты отвечают за пароли и сессии. Справочники содержат предметы и преподавателей. Расписание хранит семестры, повторения и исключения. Задания управляют сроками, выполнением и статистикой. Группы проверяют членство и роли. Файлы проверяют доступ к вложениям. Уведомления хранят настройки и планируют доставку.

## Согласованность
Отметка выполнения и история сохраняются в транзакции. Повторное завершение не создаёт второе событие. Перед отправкой напоминания обработчик проверяет срок, статус и права. Файлы имеют промежуточные состояния загрузки и удаления для восстановления после сбоя.

## Размещение
Настройки передаются через окружение. Для публичного сервера требуется HTTPS. Резервное копирование и восстановление необходимо настроить и проверить до размещения.
